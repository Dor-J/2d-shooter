- Match visuals remain procedural WebGL shapes: the layered soldier rig, weapon and object sprites, polygon and edge shading, scenery, weather, and every particle are generated from code in `apps/web/src/render/` rather than imported. `apps/web/src/render/manifest.ts` is the only place an asset path appears, and `importedAssets()` lists anything that did not come from this project — it is empty by default and `apps/web/scripts/provenance.test.mjs` fails the build if a file under `apps/web/public/art` has no row here.
- A mod may re-point an asset at its own file. Anything a mod replaces is reported as imported by `importedAssets()`, which is the list that has to be reviewed and recorded before such a mod is distributed with the game. A replacement may not escape the mod directory and may not be scaled beyond a quarter to four times its size.
- Visual regression baselines at `tests/fixtures/visual/hud-baselines.json` are digests of frames this project draws, recorded by `apps/web/scripts/visual.test.mjs`. They contain no imported imagery.
- Font loading uses Google Fonts; replace or self-host before a release that needs offline operation.
- The 97 default-name compatibility maps use original deterministic geometry, metadata, SVG previews, and a procedural PPM texture generated by `tools/map-editor`. Historical names and mode prefixes are compatibility identifiers only; no upstream layouts or assets are reproduced. Every entry passes PMS round-trip, mode/spawn validation, preview generation, signed packaging, and offline playability tests.

Before importing assets, record their path, exact upstream commit, author if known, license, any modifications, and attribution displayed to players. Keep a copy of the license text with the distributed assets.
