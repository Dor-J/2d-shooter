# Source and asset provenance

- Mechanics reference: https://github.com/soldat/soldat, `develop` branch, MIT license. No source code or binaries were copied into this repository.
- Base content reference: https://github.com/opensoldat/base, `master` branch, CC BY 4.0. No original assets have been imported yet. Its credits listing is described upstream as incomplete, so each asset must be reviewed and recorded before reuse.
- Current visuals are original procedural WebGL shapes and CSS. Current font loading uses Google Fonts; replace or self-host before a release that needs offline operation.

Before importing assets, record their path, exact upstream commit, author if known, license, any modifications, and attribution displayed to players. Keep a copy of the license text with the distributed assets.
